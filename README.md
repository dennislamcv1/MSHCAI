# MSHCAI
## Microsoft Healthcare AI Program Manager Professional Certificate
### Professional Certificate - 8 course series

Step into one of healthcare's fastest-growing entry-level support roles. This program builds your hands-on skills in Microsoft 365, Microsoft Copilot, Power BI, and Microsoft Foundry, all in the context of real healthcare AI workflows.

You'll learn to coordinate project work across Teams, SharePoint, Outlook, OneDrive, and Excel; draft meeting summaries and status updates with Microsoft Copilot using PHI-safe practices; read and interpret Power BI dashboards to monitor healthcare AI adoption; and review AI outputs from technical teams against Responsible AI and compliance checklists. A dedicated GenAI Literacy module covers responsible AI use in healthcare, and the program concludes with a Capstone in which you produce a project workspace blueprint and a first-30-day governance packet for an entry-level healthcare AI initiative.

By the end of the program, you'll be ready for entry-level roles such as Healthcare AI Coordinator, Clinical AI Project Coordinator, Healthcare AI Implementation Analyst, or Digital Health Project Coordinator—roles that build toward Healthcare AI Program Manager responsibilities over time.

This program is useful for career-changers, recent graduates, project managers, and healthcare professionals who want to support AI projects in healthcare settings. No prior AI development experience is required. General familiarity with professional workflows is helpful but not mandatory.
